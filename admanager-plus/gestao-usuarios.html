Gestão de usuários

O módulo mais usado no dia a dia — e onde os templates fazem toda a diferença entre um help desk consistente e um AD bagunçado.

As operações básicas

Criar

Um usuário por vez, em massa via CSV, ou usando um template — em AD, e opcionalmente Exchange/Microsoft 365/Google Workspace/Skype for Business simultaneamente.

Modificar

Atributos individuais, ou em bulk sobre uma lista de usuários selecionados/importados — desde dados organizacionais até licenças de Microsoft 365.

Habilitar/desabilitar/desbloquear

Ações rápidas direto na lista de usuários ou a partir de um relatório — sem precisar abrir cada objeto individualmente.

Excluir e restaurar

Exclusão em massa, com a opção de restaurar depois (ver seção abaixo).

Templates de criação e modificação

O recurso que separa uma implantação profissional de uma "gambiarra": em vez de digitar os mesmos valores toda vez que cria um usuário, você define um template que já preenche automaticamente os atributos padrão (departamento, formato de e-mail, grupos, licença de Microsoft 365, etc.), conforme a política da organização.

Template de criação

Aplica-se a novos usuários. Mudanças no template não afetam usuários já criados — só os próximos.

Template de modificação

Além de padronizar valores, permite definir regras: quando um campo específico muda, outros campos são atualizados automaticamente.

Acesse os templates

Management → User Management → User Templates — escolha Creation ou Modification.

Configure os atributos

Preencha os valores padrão por aba (Geral, Endereço/Organização, Conta, Exchange, Microsoft 365/Teams, etc.).

Defina como default (opcional)

Um template pode ser marcado como padrão — passa a ser pré-selecionado sempre que alguém cria um usuário.

Aplique via CSV, se quiser

É possível apontar qual template usar dentro de um CSV de importação, usando o atributo templateName.

MODIFICAÇÃO EM MASSA

Vários templates de criação podem ser editados ao mesmo tempo, em uma única ação — útil quando uma política organizacional muda (ex: novo formato de e-mail) e afeta vários departamentos de uma vez.

Gestão em massa via CSV

Para criar ou modificar dezenas/centenas de usuários de uma vez:

Prepare o CSV

Com os atributos necessários — cada coluna vira um campo do AD.

Importe

No assistente de criação/modificação em bulk, selecione o arquivo CSV (ou a lista "Show All Users", ou digite o nome).

Combine com template

Aplique um template por cima da importação para garantir que os campos não presentes no CSV sigam o padrão da organização.

Também é possível restringir a busca a OUs específicas ao selecionar quem será modificado, em vez de varrer o domínio inteiro.

Modificação reativa de atributos

Um recurso menos óbvio: em vez de alterar objeto por objeto, você define um valor para um atributo organizacional (ex: trocar o gerente de um departamento) e aplica a um grupo de usuários de uma só vez — a mudança "reage" sobre a lista selecionada.

Restaurando usuários excluídos

Se o AD Recycle Bin do ambiente estiver habilitado, usuários excluídos podem ser restaurados pelo ADManager Plus. Sem o Recycle Bin nativo, a restauração depende de backups — daí a importância do add-on de Backup & Recovery em ambientes que não têm essa proteção nativa habilitada.
