Infraestrutura

Requisitos de sistema e portas

O dimensionamento aqui depende muito mais do uso (quantos relatórios/automações rodam em paralelo) do que só do tamanho do domínio — vale conversar com o cliente sobre a carga esperada, não só contar usuários.

Hardware

NÃO EXISTE UM NÚMERO ÚNICO

A ManageEngine disponibiliza uma calculadora oficial de dimensionamento, porque RAM e disco variam conforme: o sistema operacional (cliente vs. servidor), o volume de relatórios e automações rodando em paralelo, e se o add-on de Backup and Recovery foi adquirido.

Faixa típica de RAM

Entre 8GB e 16GB costuma ser o ponto de partida razoável para gestão + relatórios em ambientes de porte médio, com banda de rede de 50–100Mbps.

Disco para relatórios

O cálculo considera todas as atividades de geração de relatório — sob demanda, agendadas e via automação — não só o volume de objetos do AD.

BACKUP MUDA A CONTA

Se o add-on de Backup and Recovery estiver em uso, o espaço em disco necessário passa a depender também do número de usuários protegidos em AD/Azure AD, do tamanho de caixas/drives no Google Workspace, e do período de retenção — como referência prática, 1TB de dados protegidos pede pelo menos 1TB livre para acomodar backup completo + incrementais.

Software suportado

Sistema operacional

Windows Server 2012 e versões posteriores.

Exchange

Exchange Server 2016 e versões posteriores.

Skype/Lync

LCS 2005, OCS 2007, Lync Server 2010/2013, Skype for Business Server 2015 e posteriores.

Suporta também Microsoft 365, Google Workspace e armazenamento em rede (NAS) para os cenários de gestão híbrida.

NAVEGADOR & TELA

Qualquer navegador moderno, na versão mais recente (por segurança e melhor experiência). Resolução mínima recomendada: 1366×768.

Banco de dados

PostgreSQL é o banco padrão, já embutido no instalador. MS SQL também é suportado como alternativa.

SE O AMBIENTE USA MYSQL

Instalações antigas que ainda rodam sobre MySQL devem ser migradas para PostgreSQL — é a recomendação oficial atual, já que o MySQL está sendo descontinuado como opção suportada.

Portas de rede

A regra geral: liberar conexões de saída no servidor do ADManager Plus, e de entrada nos servidores de destino (Domain Controllers e demais serviços gerenciados).

ServiçoDireçãoObservação
LDAP / LDAPSADManager Plus → Domain ControllerConsulta e alteração de objetos do AD
RPCADManager Plus → Domain ControllerOperações complementares de gestão
SMBADManager Plus → Domain Controller / servidores de arquivoRelatórios de NTFS e compartilhamentos
KerberosADManager Plus → Domain ControllerAutenticação
HTTP (padrão)Usuários → ADManager PlusPorta 8080 por padrão, alterável na instalação
CONFERIR O ATUAL

As portas específicas variam por versão e por módulo em uso (Exchange, Microsoft 365, Google Workspace cada um pode exigir portas próprias, como visto no AD360 para os mesmos serviços). Sempre confira a lista mais recente na documentação oficial antes de fechar o desenho de firewall com o time de rede do cliente.
