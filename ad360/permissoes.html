Segurança & acesso

Permissões e privilégios por componente

Cada componente exige um nível mínimo de privilégio para operar. Aqui está o resumo prático — a ideia é sair do "usa Domain Admin e pronto" para uma configuração de menor privilégio quando o ambiente exigir.

Princípio geral

RECOMENDAÇÃO OFICIAL

A ManageEngine recomenda configurar cada componente com uma conta Domain Admin para evitar travas de funcionalidade. Quando isso não é viável (ambientes com política de menor privilégio), é possível delegar permissões granulares — a tabela abaixo mostra o mínimo necessário por operação.

SINCRONIZAÇÃO

Se um componente for configurado com privilégios de Domain Admin, essas credenciais se propagam para os demais componentes integrados via AD360 — mesmo que eles tenham sido configurados manualmente com uma conta de menor privilégio.

ADManager Plus

OperaçãoPermissão mínima
Criar/editar usuáriosMembro de Administrators ou Account Operators, ou Read/Write (+ Read All Properties para editar) no objeto/OU.
Excluir usuáriosDelete All Child Objects na OU correspondente.
Restaurar usuários excluídosMembro de Domain Admins.
Gestão de grupos/computadores/contatosMesmo padrão: Administrators/Account Operators ou Read+Write granular na OU.
Gestão de GPOsMembro de Group Policy Creator Owners + permissão "Edit setting" na GPO.
Relatórios de ADPermissão de leitura (View) nas OUs/domínios — Domain Users já tem por padrão.
Gestão de caixas ExchangeExchange 2010/2013: grupo Organization Management. Exchange 2007: papel Exchange Recipient Administrator.
Gestão Microsoft 365Recomendado: papel Global Admin (ou papéis específicos como User Administrator, Exchange Administrator conforme a operação).

Alta disponibilidade / relatório de excluídos / GINAMembro de Domain Admins.

ADAudit Plus

OperaçãoPermissão mínima
Ler event logs"Manage Auditing and Security Log" + membro de Event Log Readers + permissões DCOM/WMI.
Configurar política de auditoria automaticamenteMembro de Group Policy Creator Owners.
Auditar compartilhamentos de arquivosMembro de Local Administrators no servidor de arquivos.
Auditar Azure ADPermissões de Microsoft Graph API: Application.Read.All, AuditLog.Read.All, Directory.Read.All, entre outras.

Exchange Reporter Plus

Requer, na base, LDAP Read sobre objetos do Global Catalog + View-Only Recipients RBAC para a maioria dos relatórios. Para pesquisa de conteúdo (content search), é necessário acesso completo às caixas ou o papel ApplicationImpersonation.

M365 Manager Plus

Combina papéis do Microsoft 365 (User Administrator, Exchange Administrator, Teams Administrator, Security Reader, Global Reader) com escopos de Microsoft Graph quando configurado via aplicativo Azure AD (ex: User.ReadWrite.All, Group.ReadWrite.All).

SharePoint Manager Plus

On-premises: membro do grupo de administradores do servidor SharePoint + membro de Farm Administrators. Microsoft 365: papel de SharePoint Administrator, e para auditoria, os papéis Audit Log e View Only Audit Log.
