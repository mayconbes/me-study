Relatórios & auditoria

Compliance no AD360

Uma das razões pelas quais empresas reguladas escolhem o AD360: relatórios prontos, mapeados direto para os principais frameworks regulatórios — sem precisar montar cada relatório do zero.

O que a aba Compliance faz

O AD360 gera relatórios predefinidos e prontos para auditoria a partir dos dados já coletados pelos componentes integrados (principalmente ADAudit Plus). Em vez de o time de segurança/compliance ter que caçar informação manualmente em cada ferramenta, a aba Compliance organiza tudo por mandato regulatório.

Mandatos suportados

PCI DSS

Segurança de dados de cartão de pagamento.

HIPAA

Proteção de informação de saúde (setor de healthcare, EUA).

GDPR

Proteção de dados pessoais (União Europeia).

SOX

Controles financeiros e de governança corporativa (EUA).

CCPA

Privacidade do consumidor (Califórnia).

GPG13

Boas práticas de monitoramento de segurança (Reino Unido).

FISMA

Segurança da informação para agências federais dos EUA.

GMMC

Governança e maturidade de gestão de mudanças.

POPIA

Proteção de dados pessoais (África do Sul).

RELEVÂNCIA PRA BR

Não há um relatório nomeado "LGPD" na lista padrão — mas como a LGPD segue princípios muito próximos do GDPR (consentimento, minimização de dados, direito ao esquecimento, notificação de incidentes), os relatórios de GDPR costumam servir como base de partida para clientes brasileiros, complementados pelas seções customizadas quando necessário.

Criando uma seção de compliance customizada

Quando nenhum mandato pronto cobre exatamente o que o cliente precisa (ex: uma política interna, ou um framework não listado), dá para montar a própria seção:

Abra o gerenciador

Na aba Compliance, clique em Manage Compliance no canto inferior esquerdo.

Crie a seção

Clique em Create New Compliance, dê um nome para a seção e selecione os relatórios que você quer agrupar nela.

Salve

A nova seção passa a aparecer na lista de compliance do AD360, junto com os mandatos predefinidos.

As mesmas telas permitem editar (ícone de lápis) ou excluir (ícone de lixeira) uma seção customizada já criada.
