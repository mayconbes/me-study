Glossário

Os termos que mais aparecem na documentação, explicados sem jargão.

Conceitos do AD360

Componente

Cada uma das 7 ferramentas (ADManager Plus, ADAudit Plus etc.) que se integram ao AD360. São produtos independentes.

Integração

O processo de registrar um componente no AD360 informando servidor, porta e protocolo, para que ele apareça no console unificado.

Sincronização

Propagação automática de configurações (domínio, e-mail, proxy) entre os componentes integrados.

Instalação Standard/Minimal/Custom

Os três modos de instalação: tudo automaticamente, só o núcleo, ou uma seleção sob medida de componentes.

Active Directory

OU (Organizational Unit)

Uma "pasta" dentro do Active Directory usada para organizar usuários, grupos e computadores — e aplicar permissões e políticas de forma segmentada.

GPO (Group Policy Object)

Um conjunto de configurações que pode ser aplicado a usuários ou computadores de uma OU — de senha mínima a scripts de logon.

Domain Controller (DC)

O servidor que guarda o banco de dados do Active Directory e autentica os logins do domínio.

Global Catalog

Um índice parcial de todos os objetos de todos os domínios de uma floresta AD, usado para buscas rápidas entre domínios.

LDAP

O protocolo usado para consultar e modificar informações no Active Directory (porta 389, ou 636 com criptografia SSL).

Kerberos

O protocolo de autenticação usado pelo Windows/AD para validar identidade sem transmitir a senha em texto puro.

Microsoft 365 / Cloud

Tenant

A instância isolada de uma organização dentro do Microsoft 365 — cada empresa tem o seu.

Global Admin

O papel de administrador mais alto no Microsoft 365, com acesso a todos os serviços e configurações do tenant.

Aplicativo Azure AD (App Registration)

Um "usuário de aplicação" cadastrado no Azure AD, usado para autenticação programática (API) em vez de login interativo.

Microsoft Graph

A API unificada da Microsoft para acessar dados do Microsoft 365 (usuários, grupos, e-mails, relatórios etc.).

MFA (Multi-Factor Authentication)

Autenticação com mais de um fator (ex: senha + código no celular) — exige senha de aplicativo quando habilitada em contas de serviço.

Infraestrutura

Proxy reverso

Um servidor que recebe as requisições externas e as redireciona para o serviço correto internamente — o AD360 pode atuar assim para os componentes.

Alta disponibilidade (HA)

Configuração que garante que o sistema continue disponível mesmo se o servidor principal falhar.

CSR (Certificate Signing Request)

O arquivo que você gera e envia para uma Autoridade Certificadora (CA) para que ela emita um certificado SSL válido.

Certificado autoassinado

Um certificado SSL gerado pelo próprio produto, sem validação de uma CA — funciona, mas gera aviso de "não confiável" no navegador.

DMZ (zona desmilitarizada)

Uma sub-rede isolada entre a internet e a rede interna, onde ficam servidores expostos (como um proxy reverso) sem dar acesso direto ao restante da infraestrutura.

Failover

A troca automática para um servidor reserva (standby) quando o servidor principal para de responder.

Acesso & autenticação

IdP (Identity Provider)

O serviço externo responsável por autenticar o usuário no lugar do próprio AD360 — ex: Okta, ADFS, Azure AD.

SAML

Um protocolo padrão para troca de autenticação entre um IdP e uma aplicação (Service Provider) — usado no SSO baseado em provedor externo.

NTLM

Protocolo de autenticação da Microsoft que permite login automático usando a sessão já aberta no domínio Windows.

TOTP (Time-based One-Time Password)

Um código numérico temporário, válido por poucos segundos, gerado por apps como Google Authenticator — base da maioria dos 2FA por app.

Super administrador

A conta com controle total sobre um componente específico (diferente da conta de domínio) — é ela que o AD360 pede ao integrar um componente remoto.

Comercial & compliance

Edição (Standard/Professional)

O nível de licença que define quais recursos de um componente ficam disponíveis — Professional inclui os recursos mais avançados.

Mandato regulatório

Uma norma ou lei que exige controles específicos de segurança/privacidade — ex: GDPR, HIPAA, PCI DSS, SOX — e para a qual o AD360 já tem relatórios prontos.
