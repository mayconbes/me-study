O checklist que evita retrabalho no dia da instalação: quanto de hardware reservar, quais sistemas são suportados e — o que mais gera chamado — quais portas liberar no firewall.

REGRA PRÁTICA

Se for integrar mais de dois componentes, a recomendação oficial é não colocar mais de dois componentes na mesma máquina — o consumo de RAM soma rápido.

RECOVERYMANAGER PLUS

O espaço em disco varia conforme o número de objetos, tamanho do Domain Controller e período de retenção. Compressão típica de backups de AD: proporção de até 2:1.

Plataformas, bancos e navegadores suportados

Sistemas operacionais

Windows Server 2008 até 2025, e Windows 7 até 11 (desktop).

Bancos de dados

PostgreSQL (padrão, já incluso) ou Microsoft SQL Server.

Navegadores

Microsoft Edge (qualquer versão), Firefox 4+, Chrome 10+.
