Os 7 componentes do AD360

Cada componente resolve uma dor específica de gestão de identidade. Você escolhe quais integrar conforme a necessidade do ambiente — não é preciso usar os sete.

01 · ADManager Plus

Para que serve: gestão, automação, delegação e workflows de aprovação para Active Directory, Microsoft 365, Exchange e Google Workspace.

Uso típico: criar/editar/desativar usuários em massa, delegar tarefas de help desk sem dar acesso de Domain Admin, e automatizar provisionamento (ex: integrar com RH).

CONFIGURAÇÃO

Domínio: Domain Settings → Add new domain. Tenant Microsoft 365: Admin → System Settings → Microsoft 365/Google Workspace.

02 · ADAudit Plus

Para que serve: auditoria de mudanças em tempo real e compliance para Active Directory, Azure AD e file servers.

Uso típico: rastrear quem alterou uma GPO, quem criou/excluiu um usuário, ou monitorar acesso a arquivos sensíveis em servidores Windows, NetApp e EMC.

CONFIGURAÇÃO

Segue o mesmo processo de domínio do ADManager Plus — se ambos estiverem integrados ao AD360, o domínio configurado em um já aparece no outro.

03 · ADSelfService Plus

Para que serve: autoatendimento para usuários finais — reset de senha, desbloqueio de conta, atualização de dados no diretório e SSO com MFA.

Uso típico: reduzir chamados de help desk sobre "esqueci minha senha", ao mesmo tempo em que aumenta a segurança com múltiplos fatores.

POLÍTICAS

As permissões de autoatendimento são controladas por políticas aplicadas a OUs ou grupos específicos — não é tudo ou nada para o domínio inteiro.

04 · Exchange Reporter Plus

Para que serve: relatórios, auditoria e monitoramento de Exchange Server e Exchange Online, além de relatórios para Skype for Business Server.

Uso típico: relatórios de tamanho de caixas postais, permissões delegadas, tráfego de e-mail e logs de OWA.

05 · M365 Manager Plus

Para que serve: gestão, relatórios, automação, delegação, auditoria e alertas para Exchange Online, Azure AD, Skype for Business, OneDrive, Teams e outros serviços Microsoft 365.

Uso típico: administrar um tenant Microsoft 365 inteiro sem precisar abrir o Admin Center da Microsoft para tarefas do dia a dia.

06 · RecoveryManager Plus

Para que serve: backup e recuperação de desastres para Active Directory, Azure AD, Exchange Online, SharePoint Online, OneDrive, Google Workspace, Exchange on-premises e Zoho WorkDrive.

Uso típico: restaurar um objeto do AD excluído acidentalmente, ou recuperar uma caixa de e-mail inteira sem depender de backup de infraestrutura genérico.

07 · SharePoint Manager Plus

Para que serve: gestão, auditoria e relatórios para ambientes SharePoint on-premises e Microsoft 365.

Uso típico: auditar acesso a sites e bibliotecas de documentos, e gerenciar permissões de coleções de site.
