Instalação & operação

Do instalador ao ambiente em produção

Este é o caminho prático: como instalar, os três modos disponíveis, e as configurações de produção que todo consultor precisa dominar (SSL, backup, atualização).

PROCURANDO O ROTEIRO COMPLETO?

Se você quer a sequência de ponta a ponta de um projeto de implantação (levantamento, ordem de instalação, hardening, checklist de validação), veja o Guia de implantação no cliente. Esta página aqui é o detalhe técnico de cada tela.

Três modos de instalação

RECOMENDADO

Standard

Baixa e instala automaticamente todos os 7 componentes junto com o AD360. Ideal para uma implantação completa de IAM.

QUANDO JÁ HÁ COMPONENTES

Minimal

Instala apenas o AD360. Use quando os componentes já estão rodando em outros servidores e você só quer integrá-los depois.

SOB MEDIDA

Custom

Você escolhe exatamente quais componentes instalar junto com o AD360 — nem todos, nem nenhum.

Aplicação vs. serviço do Windows

Por padrão, o AD360 é instalado como aplicação (roda com os privilégios do usuário que instalou, e precisa ser iniciado manualmente). Para produção, o recomendado é instalar também como serviço do Windows, que:

  • Roda com os privilégios da conta de sistema (ou de serviço configurada).
  • Pode iniciar automaticamente com o servidor, sem depender de login de usuário.
COMO FAZER

Depois de instalado como aplicação: Start Menu → AD360 → Install AD360 as Service, ou pelo ícone de notificação do próprio console.

Primeiro acesso

Abra o navegador

Acesse http://<hostname>:8082, onde <hostname> é o nome DNS da máquina onde o AD360 foi instalado.

Login inicial

Usuário e senha padrão: admin / admin. Troque a senha imediatamente em Admin → General Settings → Personalize → Change Password.

Habilitando SSL

Em Admin → General Settings → SSL Certification Tool existem dois caminhos:

Já tenho um certificado

Escolha Apply Certificate, selecione o componente de destino e envie o arquivo — em ZIP, certificados individuais (PFX/PEM) ou colando o conteúdo do certificado.

Não tenho um certificado

Escolha Generate Certificate, preencha os dados da organização e gere um CSR para enviar à sua CA — ou aplique um certificado autoassinado instantaneamente (gera aviso de "não confiável" no navegador).

Backup automático

O AD360 pode fazer backup do próprio banco e dos bancos dos componentes integrados, no PostgreSQL embutido ou em PostgreSQL/MS SQL externos.

Navegue até a configuração

Admin → General Settings → Database Settings → Database Backup, escolha o componente e clique no ícone de edição.

Defina a frequência

Diária, semanal ou mensal, em um horário específico.

Escolha full vs. incremental

Defina quantos backups incrementais entre cada backup completo (0 = apenas backups completos).

Caminho e retenção

Pasta local ou compartilhada, e por quanto tempo manter os arquivos de backup.

Atualização automática

Em Admin → Administration → Auto Update é possível habilitar atualização automática por componente, definir a frequência de verificação (diária/semanal/mensal) e configurar notificações de quando há atualização disponível ou quando ela é instalada.

Migração de banco de dados

O AD360 nasce com PostgreSQL embutido, mas suporta migrar para:

  • PostgreSQL externo (outra instância)
  • Microsoft SQL Server
SEMPRE

Faça backup do banco antes de qualquer migração. Para migrar para MS SQL, é preciso copiar os arquivos bcp.exe e bcp.rll do SQL Server para a pasta bin do AD360, e instalar o SQL Native Client correspondente à versão do SQL Server.
