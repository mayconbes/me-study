Operação do console

Configurações avançadas do AD360

O que fica em Admin → General Settings — a parte do console que o time de operação/suporte revisita com frequência depois que a implantação termina.

Product Settings

Ajustes de comportamento e segurança do próprio AD360:

Score de segurança

O AD360 calcula um percentual de "configurações mandatórias de segurança" aplicadas. Enquanto não chegar a 100%, um alerta fica visível no Notification Center — e, em contas licenciadas, também aparece após cada login.

Senha dos backups de banco

Por padrão, o AD360 protege os backups do banco com uma senha forte gerada automaticamente. Pode ser trocada manualmente (mínimo 8 caracteres) — mas se você perder essa senha, os backups antigos não podem mais ser restaurados.

Alerta de espaço em disco

Escolha o limite (1GB, 2GB ou 5GB) a partir do qual o AD360 avisa que o disco está ficando cheio.

Tempo de expiração de sessão

Define depois de quanto tempo de inatividade a sessão do usuário expira — importante em auditorias de segurança.

Nível de log

Controla o quanto o AD360 registra em log — útil de elevar temporariamente ao investigar um problema com o suporte ManageEngine.

LDAPS para comunicação com o AD

Se o cliente exige LDAP criptografado, é preciso importar o certificado SSL exportado do servidor LDAP para o repositório de certificados confiáveis do Windows antes de habilitar.

Console único / SSO entre componentes

Quatro chaves independentes: Single Console (acessar todos os produtos integrados pelo painel de aplicações), Single Sign-On (não pedir login de novo ao trocar de componente), Single Sign-Out (sair de tudo ao sair do AD360) e Single Shutdown (desligar todos os componentes ao desligar o AD360).

Server Settings

Onde ficam os "canais de saída" do AD360 — como ele fala com o mundo fora do domínio:

Mail Settings

Servidor SMTP, endereço de remetente e (se necessário) autenticação — usado para todos os alertas e notificações do produto.

SMS Settings

Duas opções: um modem GSM físico conectado por porta serial, ou um gateway HTTP/SMTP customizado de um provedor de SMS.

Proxy Settings

Se o ambiente do cliente exige proxy corporativo para saída à internet (ex: para verificar atualizações), configure aqui.

LEMBRETE

Essas configurações de servidor de e-mail e proxy fazem parte do que sincroniza automaticamente entre os componentes integrados — ver Arquitetura → O que é sincronizado.

Database Settings

Aqui vivem três operações distintas — não confunda uma com a outra:

Backup periódico

Agendamento de backup automático do banco embutido ou externo (detalhado em Instalação → Backup automático).

Restauração

Restaurar o AD360 (ou um componente) a partir de um backup previamente gerado.

Migração de banco

Trocar do PostgreSQL embutido para MS SQL Server ou outra instância de PostgreSQL (detalhado em Instalação → Migração de banco).

Notification Center

O sino de notificações no canto superior direito do console. Cada alerta tem um link de ação direto para a tela onde o problema precisa ser corrigido — por exemplo, um alerta de configuração de segurança pendente leva direto para a tela correspondente. Alertas que não fazem sentido para o ambiente podem ser descartados manualmente.

API Settings

Gerencia o acesso via API REST do AD360 — útil quando o cliente quer integrar o AD360 com um ITSM (ServiceNow, Zendesk) ou automatizar tarefas via scripts, em vez de usar só a interface web.

Integração com SIEM

Permite encaminhar eventos e logs do AD360 para uma solução de SIEM (como o Log360, da própria ManageEngine, ou outra ferramenta) — para quem já centraliza monitoramento de segurança fora do AD360.
