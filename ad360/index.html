Uma plataforma, sete ferramentas,
uma única visão de identidade.

AD360 é o console unificado que reúne gestão, auditoria, self-service, backup e relatórios de Active Directory, Microsoft 365, Exchange e SharePoint — tudo sincronizado automaticamente.

Guia de implantação no cliente → Ver arquitetura

Os 7 componentes se conectam ao AD360 e trocam configurações automaticamente — domínio, servidor de e-mail, proxy e credenciais ficam sincronizados entre todos.

Em uma frase

O que é o AD360, de fato?

Pense no AD360 como um hub: ele não substitui as sete ferramentas, ele as orquestra. Cada componente continua sendo instalado e rodando de forma independente — o AD360 apenas os integra em um único login, um único painel e uma única configuração de domínio, e-mail e proxy. Isso resolve o maior problema de ambientes com várias ferramentas ManageEngine: configurar tudo sete vezes.

01

Console único

Login uma vez, acesse os dashboards de todos os componentes integrados pelo painel lateral de aplicações.

02

Sincronização automática

Domínio, servidor de e-mail, proxy e credenciais configurados em um componente se propagam para os demais.

03

Instalação modular

Instale tudo de uma vez (Standard), só o núcleo (Minimal) ou escolha exatamente quais componentes quer (Custom).

04

Infraestrutura compartilhada

Um único banco de dados, uma rotina de backup, um certificado SSL e uma política de alta disponibilidade para todo o conjunto.
