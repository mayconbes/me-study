Infraestrutura

Requisitos de sistema e pré-requisitos

Além do hardware padrão, dois itens fazem ou quebram uma implantação de PAM360: a conta de serviço certa, e o dimensionamento de disco pra gravação de sessão.

Pré-requisitos essenciais (além do hardware básico)

Se o cliente vai usar descoberta automática de contas e reset de senha (ou seja, praticamente sempre), três elementos são obrigatórios:

Servidor SMTP externo

Necessário para o funcionamento do servidor PAM360 e para enviar notificações aos usuários.

Conta de serviço com privilégio

Precisa de direitos de Domain Admin (ou admin local) tanto no servidor PAM360 quanto nos sistemas-alvo gerenciados.

Microsoft .NET Framework

Necessário para as funcionalidades de descoberta e reset de senha — e para o Application Gateway, também o Visual C++ Redistributable (2015 ou superior).

Dimensionando disco para gravação de sessão

REGRA PRÁTICA

Cada minuto de sessão gravada (sem contar tempo ocioso) consome aproximadamente 1MB de disco. Multiplique pela expectativa de volume de sessões privilegiadas por dia/mês do cliente para chegar a uma estimativa realista — este é o item de dimensionamento mais frequentemente subestimado num projeto de PAM.

Software necessário

PAM360 roda em Windows ou Linux (ver Arquitetura para as diferenças práticas entre as duas opções). Um navegador compatível com HTML5 é suficiente para o console web e para lançar sessões remotas — sem necessidade de plugin.

Banco de dados

A edição Registered (Enterprise) suporta SQL Server ou cluster SQL Server como banco de dados de produção — relevante para ambientes que já têm política de banco corporativo padronizado, ou que precisam de alta disponibilidade de banco além do que o banco embutido oferece.
