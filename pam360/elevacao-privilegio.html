PEDM

Elevação e delegação de privilégio

O antídoto pro "todo mundo é admin local pra não travar o trabalho": privilégio concedido só na hora certa, pelo tempo certo.

O que é PEDM (Privilege Elevation and Delegation Management)

Uma categoria própria dentro de PAM: em vez de dar acesso administrativo permanente, o PEDM concede privilégio elevado granular e por tempo limitado — para uma aplicação, um comando, ou um sistema específico — mantendo o usuário sem privilégio o resto do tempo.

Elevação just-in-time (modo agentless)

Usuários com requisição válida são elevados automaticamente a um grupo de segurança local para acesso temporário ao sistema-alvo, e revertidos ao privilégio padrão assim que o período da requisição expira. Aplicável a contas Windows locais e de domínio.

LIMITAÇÃO DE PLATAFORMA

JIT via política de segurança local é específico para recursos Windows e Windows Domain. Para Linux, a elevação passa por outros módulos de PEDM: SSH Command Control e Self-Service Privilege Elevation.

Elevação self-service (modo com agente)

Feita instalando e configurando agentes de elevação self-service diretamente nos endpoints — permite que o próprio usuário eleve o privilégio de uma aplicação específica quando necessário, sem depender de um administrador aprovar em tempo real toda vez.

Elevação de conta de domínio via ADManager Plus

Para elevar uma conta de domínio (não só local), o PAM360 se integra ao ADManager Plus: o Domain Controller é adicionado como recurso no PAM360 e associado a grupos de segurança específicos do AD (obtidos via essa integração). A partir daí, um usuário de domínio pode herdar privilégio de domain admin temporariamente, via o mesmo mecanismo de requisição-aprovação.

QUEM MANDA POR ÚLTIMO

Por precaução de segurança, se houver conflito, mudanças feitas pelos administradores do ADManager Plus sempre prevalecem sobre as que o PAM360 tentar aplicar — o PAM360 não assume controle definitivo sobre permissões de domínio geridas por outra ferramenta.

Controle de aplicação em endpoints (Endpoint Privilege Management)

Powered by ManageEngine Application Control Plus, esse módulo vai além da elevação pontual — remove privilégio de administrador local de forma ampla, e controla o que pode rodar:

Modo estrito (allowlist)

Só aplicações na lista de permitidas podem rodar no endpoint — com a opção de conceder acesso just-in-time a algo fora da lista quando necessário.

Controle de processo filho

Define quais aplicações podem invocar processos filhos, e bloqueia isso para as demais — reduz o caminho que um processo comprometido teria para escalar.

A aba Admin Rights Summary lista todas as contas de admin local descobertas no ambiente num só lugar — o ponto de partida natural para uma limpeza de privilégios permanentes desnecessários.
