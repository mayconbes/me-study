File server & NAS

Auditoria de arquivos

Os file servers guardam a propriedade intelectual mais sensível da empresa — e são, na prática, o tipo de dado que mais aparece em investigação de vazamento.

O que é auditado

Acesso a arquivo/pasta

Quem abriu, leu ou copiou um arquivo, e quando.

Mudança de permissão

Alterações em NTFS e compartilhamentos — quem ganhou ou perdeu acesso a quê.

Criação/exclusão

Novos arquivos e pastas, e exclusões — inclusive quando um arquivo é movido para fora do escopo monitorado.

Dispositivos NAS suportados

Além de file servers Windows, a cobertura se estende a uma lista ampla de storage de terceiros: NetApp (Filer e Cluster Data ONTAP), EMC (Celerra, VNX, VNXe, Unity, Isilon), Synology, Hitachi NAS, Huawei OceanStor, QNAP, Amazon FSx (Windows e NetApp ONTAP), Azure Files, Nutanix Files, Dell (PowerScale, PowerStore, Unity XT), CTERA e Qumulo.

POR QUE ISSO IMPORTA NUMA PROPOSTA

Muita gente assume que "auditoria de AD" só cobre Windows — se o cliente tem storage de terceiros (comum em ambientes de mídia, engenharia, saúde), vale confirmar explicitamente que o modelo específico está na lista suportada antes de fechar escopo.

Monitoramento de integridade de arquivo (FIM)

Rastreia mudanças no conteúdo e nos atributos de arquivos críticos — relevante tanto para segurança (detectar alteração não autorizada) quanto para compliance (provar que dados regulados não foram adulterados).

Tempo real exige agente

Assim como em Windows Server, a auditoria de file server funciona sem agente — mas só fica em tempo real com o agente cliente instalado na máquina. Ver Arquitetura → Quando instalar o agente.
