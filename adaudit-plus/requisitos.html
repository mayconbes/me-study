Requisitos de sistema e portas

Dimensionar isso errado é a causa mais comum de um ADAudit Plus "lento" — o volume de eventos ingeridos é o que realmente pesa, não o tamanho do domínio.

MELHOR PERFORMANCE

Para ambientes grandes, a recomendação é 16 núcleos e 32GB de RAM. O espaço de disco do banco depende do volume de eventos ingeridos e da configuração de arquivamento — a forma correta de estimar é rodar o produto por um mês e consultar o gráfico de utilização em Admin → Disk space analysis.

Sistema operacional & navegadores

Sistema operacional

Windows Server 2012 até 2025, e Windows 10/11 no lado desktop (versões mais antigas seguem suportadas, mas já descontinuadas pela própria Microsoft).

Navegadores

Mozilla Firefox 3.6+, Google Chrome, Microsoft Edge. Resolução recomendada: 1024×768 ou superior.

Banco de dados

PostgreSQL é o padrão, já embutido no instalador. MS SQL Server (2012 a 2025) também é suportado — inclusive com caminho de migração de PostgreSQL para MS SQL documentado oficialmente.

GUIA DE PORTAS COMPLETO

O produto tem um guia de portas dedicado (Product and System Ports) cobrindo os requisitos completos por cenário — DC, file server, NAS, agente — sempre vale conferir a versão mais recente antes de fechar o desenho de firewall com o time de rede do cliente.
