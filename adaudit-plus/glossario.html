Glossário

Os termos que mais aparecem na documentação do ADAudit Plus, sem jargão.

Conceitos centrais

UBA (User Behavior Analytics)

Machine learning que aprende o comportamento normal de cada usuário e sinaliza desvios — sem precisar de regra manual pra cada tipo de anomalia.

Attack Surface Analyzer (ASA)

Módulo de detecção baseado em regra para técnicas de ataque conhecidas, e de exposição de configuração em nuvem.

Change auditing

Registrar não só que algo mudou, mas quem mudou, quando, de onde, e os valores antes/depois.

WEF/WEC (Windows Event Forwarding)

O mecanismo nativo do Windows para centralizar logs — o ADAudit Plus se posiciona como alternativa mais simples de configurar.

Object-level auditing

Auditoria configurada no próprio objeto do AD (não só na política geral), permitindo rastrear mudanças em atributos específicos.

FIM (File Integrity Monitoring)

Monitoramento de mudanças em conteúdo e atributos de arquivos críticos.

Técnicas de ataque comuns

Kerberoasting

Extrair hash de senha de conta de serviço solicitando um ticket Kerberos para ela.

DCSync / DCShadow

Simular (DCSync) ou registrar (DCShadow) um Domain Controller falso para extrair ou injetar dados maliciosamente.

Golden Ticket

Forjar um ticket Kerberos com acesso irrestrito e duradouro ao domínio.

Pass-the-hash / pass-the-ticket

Autenticar reutilizando um hash de senha ou ticket Kerberos roubado, sem precisar da senha original.

Password spray

Testar uma senha comum contra muitas contas, em vez de muitas senhas contra uma conta (o que evitaria lockout).

LAPS (Local Administrator Password Solution)

Solução da Microsoft para gerenciar senhas de administrador local — suas recuperações de senha são um evento sensível de auditar.

Infraestrutura de coleta

Agente (client-side)

Software instalado numa máquina monitorada para habilitar coleta em tempo real — obrigatório para tempo real em file server e Windows Server.

NAT device

Intermediário de rede usado para conectar agentes à internet ao servidor central sem expor o servidor diretamente.

Event Log Readers

Grupo do Windows cujos membros podem ler os event logs de uma máquina — um dos privilégios centrais da conta de serviço.

Baseline comportamental

O padrão "normal" aprendido pelo motor de UBA para cada usuário, usado como referência para detectar anomalias.
