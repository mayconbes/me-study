Arquitetura

Como o ADAudit Plus coleta os dados

A decisão mais importante de uma implantação: onde instalar agente, e onde não precisa.

Coleta sem agente (agentless)

Para Domain Controllers, a coleta de log acontece em tempo real sem precisar instalar nada neles — o ADAudit Plus lê os event logs remotamente. Isso é o padrão, e não deixar de instalar um agente em nenhum lugar não impede o produto de funcionar — só limita a granularidade em tempo real de alguns tipos de dado.

Quando instalar o agente cliente

Redes distribuídas via WAN

Em ambientes espalhados geograficamente com links WAN, o agente reduz consumo de banda e estabiliza a coleta — recomendado a partir de ~1000 estações de trabalho.

Tempo real em file server e Windows Server

Sem o agente, a coleta desses dois tipos de servidor ainda funciona, mas não em tempo real. O agente é o que habilita a granularidade imediata para eles.

COMO INSTALAR

Manualmente, ou em massa via ManageEngine Endpoint Central (pacote MSI + arquivo MST para customização). O agente se conecta ao servidor por padrão na porta 8555, via HTTPS — e não exige reiniciar a máquina após a instalação.

Deployment via NAT (acesso pela internet)

Para expor o ADAudit Plus de forma segura pela internet — cenário comum quando há agentes fora da rede corporativa —, um dispositivo NAT (Network Address Translation) atua como intermediário entre o agente cliente e o servidor central, sem expor o servidor diretamente.

Fontes de dados suportadas

Identidade híbrida

Active Directory (2008+), Entra ID (Azure AD), AWS Managed Microsoft AD, AD FS, AD Certificate Services.

Servidores & estações

Windows Server 2008+, estações Windows XP+, e estações macOS Catalina 10.15+.

Armazenamento

File servers Windows, e uma lista extensa de NAS: NetApp, EMC, Synology, Hitachi, Huawei, QNAP, Amazon FSx, Azure Files, Dell, Nutanix, entre outros.

Segurança em nuvem

Attack Surface Analyzer para Azure, AWS e Google Cloud Platform — detecção de exposição, não só de mudanças.
